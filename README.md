# Jordan Hartfiel | Technical Product Portfolio

A static HTML, CSS and JavaScript portfolio. Intended to be published as a standalone **public** GitHub repository, separate from the private work repository.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `jordan-hartfiel-portfolio` under `jhartfiel4` at https://github.com/new. Do not initialize with a README because this folder includes one.
2. In the new repository select **Add file → Upload files**, drag in `index.html`, `styles.css`, `script.js`, `Jordan_Hartfiel_Resume.pdf`, `.nojekyll` and `README.md`, then **Commit changes**. Note that hidden `.nojekyll` may need to be created directly in GitHub if the upload picker hides it; it is optional for this site.
3. Open repository **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. When deployment succeeds, open `https://jhartfiel4.github.io/jordan-hartfiel-portfolio/`.

Any future changes can be uploaded or committed to `main` and GitHub Pages will redeploy.

## Files

- `index.html`: homepage, three case studies, reconstructed architecture diagrams
- `styles.css`: responsive appearance
- `script.js`: case study navigation
- `Jordan_Hartfiel_Resume.pdf`: linked resume
- `.nojekyll`: prevents Jekyll processing
